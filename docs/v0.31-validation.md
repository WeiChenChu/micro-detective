## 架構與體驗

- `academyStages` 定義五階段，以 `toolIds` 關聯六筆 `observationTools`／`ToolKnowledge`。Notebook、ToolSummary 依工具資料生成；Academy 導航、完成條件與進度依階段生成。
- `MagnifierLab` 同時承載肉眼、稍微靠近、放大鏡及發現四個步驟。共用背景 DOM、`specimenFrame` 與熱點座標；靠近時僅小幅調整視距，拿起鏡片前後背景尺寸與相對位置完全一致。鏡片內用同一素材放大 2.5×。
- 找到果蠅頭、翅膀、身體或腳才開啟下一階段；葉片保留為發現後的可選探索。進入解剖顯微鏡繼續看同一種果蠅，轉到洋蔥前明確更換細胞問題。
- `ObservationView` 在每個主要互動觀察區顯示目前工具，插圖與名稱直接來自 `toolIllustrations.ts`，使用 Notebook 原有 SVG；圖示 alt 留空，由可見工具名稱提供無重複的無障礙名稱。工具變更與電子模式使用 polite status。
- 桌面右側插圖 112×98px；沿用 680px breakpoint，手機改成上方工具名稱列與 64×56px 插圖。主觀察區保持獨立寬度。手機方向按鈕改兩欄，工具回顧的英文長名稱可換行。
- 保留 StereoLab 倍率／視野、複式光學對焦、螢光三通道、SEM／TEM 切換。電子顯微鏡共用同一儀器插圖，獨立標示 SEM 表面／TEM 內部。
- 已完成階段仍可直接繼續；重新探索時，不會在尚未操作前顯示這次的發現句。

## 進度遷移

`schemaVersion = 2`、`CONTENT_VERSION = 4`、storage key 及 24 小時失效規則不變，`academyRevision` 升為 3。

- `academyCompleted` 保存階段 ID；`learnedTools` 保存獨立工具 ID。`COMPLETE_ACADEMY_STAGE` 同時完成階段並以 `toolIds` 收藏對應工具。
- 舊 revision 2 的六課 index 0／1 → 新 index 0，2–5 → 新 index 1–4；首頁 null 不變。
- 所有舊收藏保留為工具。只有肉眼和放大鏡都完成才將第一階段標為完成；只完成其中一課可保留原卡並繼續合併階段，不必重玩其他已完成階段。
- 任務、作答、語言、筆記本旗標與既有練習進度保留。較早四課格式依舊 ID 轉換；不存在的練習欄位沿用既有預設。
- 新格式寫回後不重複遷移；損毀、過期、不相容資料仍按原政策處理。任務重玩保留兩種 Academy 進度；下一位小偵探清空兩者，不動無關 storage key。
