# v0.2 遷移分析（實作前）

## v0.1 基準
React 19、TypeScript、Vite、原生 CSS；無路由套件、後端或帳號。App 按 reducer.screen 顯示 landing/game/complete。gameState 管理答案、多選、提示、兩次後協助、隨機最終題與 localStorage。gameData 是雙語題庫；images 管理本機 SVG 教學示意圖與出處。10 個既有測試全部通過；工作目錄原本乾淨。

原流程：首頁 → 肉眼／光學／螢光／電子各一題 → 五張隨機辨識圖 → 徽章。教學與應用混合；筆記本只收任務證據。

## 最小變更設計
保留建置、依賴、所有圖片與 GameShell、Modal、MicroscopyImage、ImageChoice、QuestionCard、FeedbackPanel、StageIntro、ProgressTracker、BadgeScreen。擴充現有 reducer，不引入全域狀態或路由套件。FluorescenceLab 移入課程；筆記本增加四張知識卡。

首頁兩條自由入口：課程（尺度、光學、螢光、電子）與任務（尺度、尋找目標、影像證據、研究問題選工具、三步最終案件）。以學習 → 觀察 → 應用 → 回饋 → 複習串接。每個課程包含一項互動與短檢核，完成授予卡片。任務玩家可借閱未收藏的卡片，避免未修課無法查閱。完成課程可重看，重玩任務保留課程卡片。

## 風險與相容策略
- 新題與舊答案不相容：v0.2 使用獨立儲存鍵，舊鍵保留；只遷移舊版語言，不宣稱舊題等同新題通關。
- 隨機順序破壞最終敘事：三個研究問題使用固定順序。
- UI 假定工具就是關卡：工具 icon 對應與任務進度分開。
- 寫死九題：總數與最終題數由資料取得。
- 重玩清掉學習獎勵：START 保留課程卡；RESET 為明確下一位玩家才清空。
- 重新整理／切換課程可能丟失任務：保存任務 cursor、selection、feedback，課程另存 module 與完成卡。
- 鍵盤焦點／對話框／減少動態：沿用原機制並補新畫面焦點；驗證窄螢幕。
- 原 SVG 並非實拍：持續標示教學示意；不以色彩作為判斷工具的唯一依據。

## 實作順序與驗證
1. 基準測試與分析。
2. 課程資料、首頁雙入口、卡片與 reducer 擴充；建置保持可玩。
3. 應用型題庫、四種代表影像與固定最終案件；回饋第二次給強提示。
4. 完整 reducer／資料驗證、瀏覽器完整流程、語言、續玩、重玩、筆記本、窄版與鍵盤；更新文件更新既有 Site 的本機版本與預覽。
